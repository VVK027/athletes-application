# App Icons & Splash Logos

Place your app branding assets in this directory:

1. `app_icon.png`: High-resolution 1024x1024 PNG image for app launcher icon.
2. `splash_logo.png`: High-resolution PNG image for splash screen center logo.

### Generating Launcher Icons & Splash Screens

Run the following commands in your terminal:

```bash
# Generate app icons for iOS, Android & Web
dart run flutter_launcher_icons

# Generate native splash screens for iOS & Android
dart run flutter_native_splash:create
```
